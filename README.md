# Armor Hider

Клиентский мод для Fabric 1.21.1. Прячет броню визуально, чтобы был виден скин.

Это **клиентский** мод: ставится в свою папку `.minecraft/mods`, а не на сервер.
Скрытие работает только на твоём экране. Остальные игроки видят броню как обычно,
и защита продолжает действовать в полном объёме — меняется исключительно картинка.

## Управление

Одна клавиша — `H`. Нажал: броня и элитры пропали у всех игроков сразу, включая
тебя. Нажал ещё раз: вернулись.

Клавиша меняется как обычно: `Esc` → Настройки → Управление, раздел «Armor Hider».
При нажатии над хотбаром появляется подсказка о текущем состоянии.

Состояние сбрасывается при перезапуске игры.

## Сборка

Как и SimpleAuth, через GitHub Actions:

1. Создай новый репозиторий, залей туда содержимое этой папки.
2. Вкладка Actions, дождись зелёной галочки.
3. Скачай артефакт `armorhider-jar`.

Локально: `gradle build`, файл появится в `build/libs`.

## Установка

Готовый `armorhider-1.1.0.jar` положи в `.minecraft/mods` рядом с Litematica
и остальными. Нужен Fabric API — он у тебя уже стоит.

На сервер этот jar класть не надо: он помечен как клиентский и там просто
не запустится.
